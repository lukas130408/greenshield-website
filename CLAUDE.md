# Greenshield Website – Regeln für Claude

## Sprache
- Die Webseite selbst (alle Texte, Überschriften, Buttons, Meta-Angaben) ist auf **Englisch**.
- Mit mir (dem Projektinhaber) kommunizierst du immer auf **Deutsch**.
- Commit-Nachrichten schreibst du auf Deutsch.

## Erklärungen
- Ich bin Anfänger. Erkläre jede Änderung in einfachen Worten: was du gemacht hast, warum, und was das für die Webseite bedeutet.
- Fachbegriffe kurz erklären, wenn sie das erste Mal vorkommen.

## Git-Workflow
- Nach jedem abgeschlossenen Arbeitsschritt automatisch committen und zu GitHub pushen, ohne vorher nachzufragen:
  1. `git add` mit den geänderten Dateien
  2. `git commit -m "<kurze, verständliche Beschreibung auf Deutsch>"`
  3. `git push`
- Remote: https://github.com/lukas130408/greenshield-website (Branch `main`)
- Niemals Dateien mit Zugangsdaten oder Geheimnissen (z. B. `.env`) committen.
- Wenn das Pushen fehlschlägt, mir den Fehler einfach erklären und nicht mit Gewalt (`--force`) pushen.
